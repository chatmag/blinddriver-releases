BlindDriver

Навігатор для України, який не губиться, коли GPS заглушено або підмінено.

Коли супутникова позиція пропадає чи «стрибає», BlindDriver продовжує вести по маршруту за розрахунком: датчики телефона, останній надійний GPS і позиції за мережею. Він чесно показує, наскільки йому можна довіряти, і дає швидко підправити позицію.

  • Завантажити останню версію (APK)
  • Довідка по всіх значках і функціях
  • Група в Telegram: питання, ідеї, обмін досвідом
