# BlindDriver: випуски

Готові збірки застосунку **BlindDriver** для Android: навігатор для України, який продовжує вести по маршруту, коли GPS заглушено або підмінено. Тут лежать лише скомпільовані APK та опис випуску `release.json`; вихідний код закритий.

## Установка

1. Скачайте `BlindDriver-<версія>.apk` з розділу **Releases** та відкрийте файл на телефоні.
2. Android попросить дозволити встановлення з цього джерела: дозвольте один раз.
3. Google Play Захист може повідомити, що не перевіряв застосунок. Кнопка «Перевірити» надсилає файл у Google на сканування: це ваш вибір.
4. Далі застосунок сам раз на добу перевіряє, чи є новіша версія, і пропонує оновитися.

## Довідка

Опис усіх значків і функцій: [BlindDriver-Help.html](https://github.com/chatmag/blinddriver-releases/releases/latest/download/BlindDriver-Help.html) (файл із розділу Releases; та сама довідка є в застосунку: «Налаштування → Довідка»).

## Як працюють оновлення

- Застосунок читає `release.json` з останнього випуску цього репозиторію.
- Після появи нової версії є **30 днів**, щоб оновитися; потім побудова нових маршрутів блокується до оновлення. Ведення, що вже йде, це не перериває.
- Перед встановленням застосунок перевіряє контрольну суму (SHA-256) і підпис файла.
