# BlindDriver: навігатор для України, який не губиться, коли заглушено GPS

**BlindDriver** — навігатор для Android (iPhone: тестова версія в TestFlight) для водіїв, які їздять там, де GPS глушать або підміняють. Коли супутникова позиція пропадає чи «стрибає», він не завмирає і не веде у поле, а продовжує вести по маршруту за розрахунком.

## Можливості

- **Ведення без GPS.** Розпізнає глушіння й підміну, не пускає хибні позиції на карту й веде за датчиками телефона, останнім надійним GPS і позицією за мережею.
- **Швидкість з машини.** OBD-адаптер ELM327 (Bluetooth або Wi-Fi) уточнює розрахунок без GPS.
- **Android Auto:** карта, ведення, швидкість і знак обмеження, пошук, «Додому» й «На роботу» (у версії з Google Play).
- **Голосовий ввід адреси** українською, російською й англійською, розумний пошук закладів, уточнення через Google.
- **Камери й світлофори** з вбудованою базою, що працює без мережі.
- **Офлайн по всій Україні:** маршрути за графом доріг і пошук адрес без інтернету.
- **Вантажний режим і ґрунтові дороги,** кілька варіантів маршруту, проміжні точки, збережені маршрути й адреси.
- **Одна підписка на двох пристроях** (телефон і планшет або два телефони), резервна копія для переходу на новий телефон.

## Чим відрізняється

- **Не вірить сліпо GPS.** Звичайні навігатори довіряють позиції телефона, тож під глушінням маркер завмирає чи стрибає. BlindDriver відкидає недовірені позиції й веде далі.
- **Показує глушіння й точність чесно:** індикатор **GPS ⚡**, сіра стрілка й коло похибки, час без GPS.
- **Поправка одним дотиком:** кнопки ↑100 і ↓100 зсувають позицію вздовж маршруту.
- **Створений для України:** алгоритми налаштовуються за реальними поїздками під глушінням.
- **Без реклами й облікового запису.** Логи поїздок записуються лише за вашим бажанням.

## Пробний період і тарифи

Перші **15 днів** — усі функції без картки й реєстрації. Далі застосунок переходить на безкоштовний тариф і лишається робочим: ведення без GPS і захист від глушіння є на всіх тарифах. Деталі й ціни: [сторінка тарифів](https://chatmag.github.io/blinddriver-releases/pricing.html).
